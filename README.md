# RED RIFT

Неоновая воздушная боевая гонка в браузере: вы и четыре соперника под управлением ИИ, три круга по 18-километровой пустынной трассе — каньоны, каменные арки, тоннель в горе, обрыв над долиной с обломками флагмана.

**Играть:** https://verysmartsoft2.github.io/red-rift/
**Офлайн-версия:** [Red_Rift.html](Red_Rift.html) — один файл, открывается с диска без интернета (нужен браузер с WebGL 2).

## Правила (по ТЗ)

- 3 круга по ~18 км, около 9 минут; 18 контрольных точек на круг, проходятся по порядку.
- Самолёт сам летит по трассе: вы выбираете высоту и боковую линию. Обратного хода и зависания нет.
- После гибели — возврат через 4 с с откатом до 250 м в пределах текущего круга; короткая защита запрещает атаковать и подбирать кейсы.
- Один предмет в слоте; из каждой группы кейсов — один подбор за круг, гибель отметку не сбрасывает.
- 4 уровня ИИ, всегда один игрок и 4 NPC.

## Содержимое

- 5 самолётов (KESTREL, MIRAGE, BASTION, ARC, NOMAD) — свои характеристики, активная особенность (Q) и 5 окрасок у каждого, плюс свои цвета и 4 покрытия.
- Модели сделаны в Blender: профилированные крылья с элеронами и рулями, кабина с рамой и пилотом, двигатели с лепестками сопла и вращающейся турбиной, пушки, ракеты на пилонах, воздухозаборники, навигационные огни, запечённый ambient occlusion.
- 4 лазера и 4 типа ракет; камера своей ракеты (R) — управление самолётом сохраняется.
- Кейсы (E): ускоритель, тормозное поле, Nova, щит, ремкомплект, голографический след, ЭМИ, а также рой дронов, фаза и гравитрос.

## Управление

| Кнопки | Действие |
|---|---|
| A / D, ← / → | Влево / вправо |
| W / S, ↑ / ↓ | Вверх / вниз |
| Ctrl (или Shift) | Воздушный тормоз |
| Space / ЛКМ | Лазер |
| F / ПКМ | Ракета |
| R | Камера ракеты / вернуться |
| E | Предмет из кейса |
| Q | Особенность самолёта |
| C | Смена камеры |
| Esc / P | Пауза |
| M / N | Звук / музыка |

На телефоне и планшете: стик слева, кнопки лазера, ракеты, кейса, особенности, тормоза и камеры ракеты справа. Поддерживается геймпад.

## Разработка

Статический сайт на Three.js без сборки: `index.html` + `js/`. Модели — `models/*.glb`.

```bash
npm install          # three, esbuild, шрифты — для тестов и офлайн-сборки
npm test             # проверка правил ТЗ на симуляции (без браузера)
npm run build        # собрать Red_Rift.html (код, three.js, стили, шрифты и модели в одном файле)
```

Пересборка моделей в Blender 5.x:

```bash
blender -b --factory-startup --python tools/blender/build_ships.py -- models renders
```

Второй аргумент — папка для превью-рендеров (`-`, чтобы не рендерить); дальше можно перечислить нужные самолёты.
